Web Terminal is a lightweight, secure, and incredibly fast tool that brings your machine's command line directly to your web browser. Perfect for remote management, quick edits, and seamless developer workflows.

Why use Web Terminal?

Zero Latency

Built on pure WebSockets. Keystrokes are transmitted and rendered with practically zero overhead.

Secure by Default

Supports native HTTPS and wss:// out of the box. Your terminal sessions are fully encrypted.

Cross-Platform

Access it from Windows, macOS, Linux, or even your iPad. If it has a browser, it has a terminal.

Resource Friendly

Minimal memory footprint. It runs quietly in the background without draining server resources.

Ways to Run

Choose the installation method that fits your environment.

Clone the repository and install dependencies. Recommended for users who want to modify the source code.

# 1. Clone and install
git clone https://github.com/your-username/web-terminal.git
cd web-terminal
npm install

# 2. Test run the application
npm run start

# 3. Setup to start on boot (using PM2)
npm install -g pm2
pm2 start npm --name "web-terminal" -- start
pm2 startup
pm2 save

Install globally via NPM. Quickest setup for node environments. Make sure your local files/repo configurations are updated if required.

# 1. Install globally
npm install -g web-terminal-cli

# 2. Run initialization (creates config files in current dir)
web-terminal init
# Update the generated config.json with your specific repo/folder paths

# 3. Run securely on startup with PM2
npm install -g pm2
pm2 start web-terminal --name "web-terminal-service"
pm2 startup
pm2 save

Download a single standalone executable. No Node.js or dependencies required on the host machine.

  1. Download the latest executable for your OS from the Releases page.
  2. (Linux/macOS) Make the file executable: chmod +x web-terminal-linux
  3. Run the application by double-clicking or running via CLI.
Starting on Boot
Windows

Press Win+R, type shell:startup, and place a shortcut to the .exe inside the folder.

Linux

Create a systemd service file pointing to the executable and run systemctl enable web-terminal.
